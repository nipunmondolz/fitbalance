# Project Scope

## Implemented MVP

### Onboarding & Personalization
- Bangla/English welcome flow
- Consent & Safety gate
- Personal information
- Goal selection
- Lifestyle assessment
- Personalized calorie target result
- Plan confirmation and persistent startup restore

### Today
- Goal summary
- Calorie progress
- Daily health summary
- Dynamic guidance
- Quick navigation to logging/actions

### Daily Log
- Meals
- Water
- Soft drinks
- Exercise
- Sleep
- Date-specific local persistence
- Delete confirmation

### Plan / Habits
- Three fixed health habits
- Date-specific completion
- Daily check-in
- Local reminder enable/time selection
- Daily scheduled notifications
- Restart persistence

### Progress
- Weight history
- Dated weight entry/edit/delete
- Target weight
- Goal progress
- BMI
- Healthy-weight reference range
- Seven-day progress summaries/charts
- Metric/Imperial display

### Learn
- Eight bilingual health/lifestyle lessons
- Category filtering
- Article detail views
- Source labels and health disclaimer

### Profile
- Health-profile overview
- Lifestyle preference editing
- Reassessment/calorie-target update
- Safe full assessment restart
- Bangla/English setting
- System/Light/Dark setting
- Metric/Imperial setting
- Privacy reset / delete-all local data

### Engineering
- Local SharedPreferences persistence
- Timezone-aware Android local notifications
- Automated calculation/unit tests
- Git-based incremental commits
- Physical-device regression testing

## Intentionally Out of Current Scope

- backend/API
- authentication
- PostgreSQL or remote database
- cloud sync
- admin panel
- AI/ML recommendation engine
- user-created habits
- food favorites
- weekly generated report
- social/community features
- FCM/cloud push notifications

## Why This Scope

The final project is intentionally presented as a **focused offline solo MVP** rather than claiming the larger original proposal architecture. This makes the repository more credible for portfolio review because implemented functionality, limitations, and technical decisions are explicitly separated.
